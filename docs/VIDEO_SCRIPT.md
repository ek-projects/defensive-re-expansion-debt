# 60-second submission video — DRED

## 0–9 s — Problem

**Visual:** second-last-line break, then the defence collapsing toward the ball.

**Voice:**
"A line break is only the start of the problem. What matters next is whether the defence can reopen and restore lateral coverage. Static compactness cannot measure that recovery."

## 9–22 s — Metric

**Visual:** team width through time, with abnormal contraction shaded.

**Voice:**
"Defensive Re-Expansion Debt, or DRED, compares each team's live width with its own normal width for that defensive phase. It accumulates when the team stays abnormally narrow. DRED intensity measures how severe that contraction is without rewarding a longer possession."

## 22–42 s — External validation

**Visual:** `figures/dred_epv_validation.png`.

**Voice:**
"Across 603 line-breaking player possessions in the ten official Dynamic Events matches, DRED intensity is positively associated with SkillCorner EPV gain. After controlling recovery duration, action duration, starting EPV and static width, the median per-match partial relationship is 0.154, with a match-bootstrap interval from 0.044 to 0.268."

## 42–53 s — Mechanism

**Visual:** `figures/dred_bodypose_validation.png`.

**Voice:**
"The two Body Pose games point in the same tactical direction: when the defence is abnormally contracted, defenders are also less oriented outward, consistent with a team that is not ready to re-expand."

## 53–60 s — Close

**Visual:** matched case study, project title and repository.

**Voice:**
"DRED is an open-source coaching diagnostic for finding and comparing failed recovery after penetration — not another black-box prediction score."
